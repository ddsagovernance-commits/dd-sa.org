## 1. Navigation — site-wide inconsistency (33 of 36 pages affected)
The global nav bar was three different versions depending on the page: a 14-link version (home only),
an 11-link version (most interior pages), and a 10-link version (cite.html, contact.html, glossary.html).
**Stratification**, **Glossary**, and **About the Architect** were missing from the nav on most pages;
contact/cite/glossary were additionally missing **Principles** and **Introduction Video**.
→ Normalised every page to the same 14-link nav as the homepage. `reader.html` and `stratification.html`
keep their intentional minimal header (immersive tool design) — not touched.

## 2. Footer tagline drift (2 pages)
`assemblies/index.html` and `faq/index.html` had the footer tagline "Resident‑led civic architecture for
the British Isles." instead of the standard "Resident‑led democratic innovation for the United Kingdom."
→ Normalised to match every other page.

## 3. Title-tag and brand-mark HTML entity inconsistency (4 pages)
`cite.html`, `contact.html`, `glossary.html` and `index.html` used HTML-entity-encoded ampersands/dashes
(`DD&amp;SA &ndash; Contact`) while every other page used raw characters (`DD&SA – Contact`). Also affected
the in-page "DD&SA" brand-mark next to the nav, and the nav link labels themselves ("Why DD&amp;SA?").
→ Normalised all four to raw characters, matching the convention used across the rest of the site.

## 4. Orphan / duplicate files removed
- **`sortition-machine.html`** — an older, unlinked draft of `stratification.html` (same tool, missing
  the copy-deterrent script the live version has). Not in the sitemap, not linked anywhere. Deleted.
- **`assemblies/future.index.html`** — an older, unlinked draft of `assemblies/index.html` (missing the
  "pending assembly" tooltip states the live version has). Not in the sitemap, not linked anywhere.
  Deleted. This also removed a duplicate `<meta name="description">` that both files shared.

## 5. Genuinely orphaned (but legitimate) pages — now linked in
Three real, content-complete pages had no inbound link from anywhere on the site, so a visitor could
only reach them by guessing the URL or via Search Console:
- **`about/why-the-uk-needs-ddsa.html`** → added a link from the end of `about/why-ddsa.html`
  ("For the structural case set out point by point, see Why the UK Needs DD&SA →").
- **`blueprint/decision-cycle.html`** and **`blueprint/sortition-process.html`** → linked from their
  matching diagram captions on `blueprint/index.html`.
- **`get-involved/index.html`** → added to the site-wide footer utility links (alongside Contact,
  Cite this work) so it's reachable from every page, not just by direct URL.

## 6. Broken sitemap entry
`sitemap.xml` referenced `downloads/DDSA-CJA-001-Civic_Justice_Architecture.pdf` — a filename that doesn't
exist on disk (the two real files are `...Civic Justice Architecture.pdf` and
`...Civic_Justice_Architecture_CJA-001.pdf`, both already correctly in the sitemap). This stale entry
would 404 if Google ever crawled it. Removed. (All 60 real corpus PDFs were already correctly linked from
`downloads.html` — that part was already solid.)

## 7. Missing Open Graph / Twitter Card tags — every page
No page on the site had `og:title`, `og:description`, `og:image`, or Twitter Card tags. This means links
shared on X, LinkedIn, Slack, or in emails would show a bare URL with no title, description, or preview
image. Added full OG + Twitter Card tags to all 36 pages, using each page's existing title/description and
`/assets/resident-journey.png` as a default share image.
**Recommended next step:** that image is 1536×1024 (not the ideal 1200×630 social-card ratio) and is a
generic stand-in. Worth commissioning one purpose-built share image before the 1 July launch.

## 8. Missing meta description / canonical tag
`stratification.html` had neither. Added both.

## 9. Meta description lengths
Tightened four descriptions that were either too long (243, 184, 171 chars) or too short (36 chars) to
land in the ~150–160 character sweet spot for search snippets, without changing their meaning:
`about/why-ddsa.html`, `glossary.html`, `essays/deliberation.html`, `contact.html`.

## 10. Copy fix
`about/the-architect.html` — "Ian R. Graham / Is the architect, planner..." read as a sentence with no
subject when the heading and paragraph are parsed separately (e.g. by a screen reader). Changed to
"He is the architect, planner…"

## 11. #join anchor added for external linking (e.g. Facebook)
There was no `about/index.html` page and no `#join` anchor anywhere on the site — a link to
`/about/index.html#join` would not work. Added `id="join"` to the top of `get-involved/index.html`,
so `https://dd-sa.org/get-involved/#join` is now a valid, working deep-link.
